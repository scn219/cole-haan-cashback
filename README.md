## How to enter a promo code at Cole Haan checkout

The promo code field sits on the checkout page, just above the order summary — after you've added items to your cart and clicked through to payment. A few practical details that trip people up:

1. Codes are **case-sensitive**, so enter them exactly as provided.
2. The code applies the moment you hit "Apply" — if the total doesn't change, it didn't take.
3. Most codes **exclude Final Sale items and gift cards**, so don't expect a discount to stick to a clearance-order combo.
4. You can't stack multiple codes on one order. Pick the single one that saves the most.
5. Codes must be applied before payment — Cole Haan won't retroactively apply a code to an order you already placed.

If a code refuses to work and none of the above explains it, the exclusion list probably does. Each code carries its own terms, and sale-section items are frequently carved out.
